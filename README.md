# Superpaper to Plasmalogin Sync for Dual-Monitor Setups

Synchronize wallpapers generated by [Superpaper](https://github.com/hhannine/superpaper) with PlasmaLogin and kscreenlocker.


Personally I'm using this fork [Superpaper-Next](https://github.com/mauro-lanza/superpaper-next)

This project installs:

- A systemd.path unit that watches Superpaper's temporary wallpaper directory:
    - `/etc/systemd/system/superpaper-to-plasmalogin-sync.path`
- A systemd.service unit that copies changed wallpapers to PlasmaLogin's wallpaper directory with the correct permissions:
    - `/etc/systemd/system/superpaper-to-plasmalogin-sync.path`
- A PlasmaLogin wallpaper plugin named superpaper.to.plasmalogin:
    - `/usr/share/plasma/wallpapers/superpaper.to.plasmalogin`
- [kscreenlocker](https://github.com/KDE/kscreenlocker) wallpaper plugin has to be manually set in the settings app
    - `System Settings -> Screen Locking -> Configure Appearance`

## Requirements:

- Linux with systemd
- Superpaper
- PlasmaLogin
- A KDE Plasma desktop environment

## Installation

Clone the repository and run the installation script:

```bash
git clone <repository-url>
cd superpaper-to-plasmalogin-sync
chmod +x setup.sh
./setup.sh
```

The installer will:

- Install the superpaper.to.plasmalogin wallpaper plugin.
- Make a /etc/plasmalogin.conf.d/90-superpaper-to-plasmalogin.conf (See KDE Bugs)
- Install the superpaper-to-plasmalogin-sync.path and service unit.
- Enable and start the path unit.

After installation, logout or reboot the system for all changes to take effect.

## KDE Bugs:

The wallpaper source can't be changed in `System Settings -> Login Screen -> Configure Appearance` and has to be done by editing /etc/plasmalogin.conf

The installer does this for you.

See: [KDE Forum](https://discuss.kde.org/t/solved-plasma-login-manager-how-to-use-a-custom-wallpaper-plugin/45020/2) or [Arch Wiki](https://wiki.archlinux.org/title/Plasma_Login_Manager#Custom_wallpaper_plugins)

## How It Works

### The services

Superpaper stores generated wallpapers in: `$HOME/.cache/superpaper/temp`

`superpaper-to-plasmalogin-sync.path` watches this directory for changes.

When a change is detected, it starts `superpaper-to-plasmalogin-sync.service` with a set delay (default 3 seconds).

Images are copied from:

`$HOME/.cache/superpaper/temp` to: `/var/lib/plasmalogin/wallpapers`

and the owner is set to plasmalogin:plasmalogin.

### Plasma Wallpaper Plugin superpaper.to.plasmalogin

A PlasmaLogin wallpaper plugin/addon/plasmoid that sets the copied wallpapers from left to right.

At the moment only dual monitor.

## Verifying the Installation

Check services:

`systemctl status superpaper-to-plasmalogin-sync.path`

`systemctl status superpaper-to-plasmalogin-sync.service`

Check logs:

`journalctl -u superpaper-to-plasmalogin-sync.service`

`journalctl -u superpaper-to-plasmalogin-sync.service -f`

### Testing the Synchronization

Make sure Superpaper has generated at least one wallpaper, then inspect the source directory: `ls -la "\$HOME/.cache/superpaper/temp"`

The synchronized files should appear in: `ls -la /var/lib/plasmalogin/wallpapers` with the correcct permissions.

You can also manually trigger the service: `sudo systemctl start superpaper-to-plasmalogin-sync.service`

## Uninstallation

Run:

`./setup.sh`

The uninstaller will:

- Disable and stop the synchronization units.
- Remove the installed systemd units.
- Remove the superpaper.to.plasmalogin plugin.
- Remove plasmalogin.conf.d override.

After uninstalling, logout and back in or reboot the system.
